# Clase 02 – Apuntes

## Actividad: Resume en HTML

Se desarrolló un CV personal usando HTML y CSS puro, sin frameworks externos.

- Estructura semántica con `<div>` y clases bien definidas
- Layout de dos columnas con CSS Grid
- Diseño responsivo con `@media` queries
- Estilos propios: gradiente en header, badges, barras de habilidades
